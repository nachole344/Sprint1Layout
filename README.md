# 🏎️ I Show Speed

**I Show Speed** es una aplicación móvil desarrollada para Android que permite consultar información relacionada con el mundo del motor, centrándose principalmente en la Fórmula 1 y MotoGP.

El objetivo del proyecto es crear una aplicación sencilla, visual e intuitiva para que los aficionados puedan acceder fácilmente a información sobre los pilotos, las clasificaciones y las estadísticas de las competiciones.

## 📱 Características principales

- **Selección de competición:** pantalla inicial para elegir entre Fórmula 1 y MotoGP.
- **Pilotos:** sección para consultar información de los pilotos.
- **Clasificación:** apartado dedicado a las posiciones de los pilotos en el campeonato.
- **Estadísticas:** sección destinada a mostrar datos relevantes de la competición.
- **Calendario:** espacio para consultar los eventos y las carreras.
- **Interfaz visual:** diseño oscuro con detalles deportivos, tarjetas e imágenes relacionadas con el mundo del motor.
- **Navegación:** diferentes pantallas para organizar el contenido de la aplicación.

## 🛠️ Tecnologías utilizadas

- **Java:** lenguaje de programación utilizado para desarrollar la aplicación.
- **XML:** diseño de las interfaces de usuario.
- **Android Studio:** entorno de desarrollo.
- **Gradle:** gestión de la configuración y las dependencias del proyecto.

## 🎨 Diseño

La aplicación utiliza una interfaz de estilo deportivo, con un fondo oscuro y elementos visuales que facilitan la navegación.

El diseño está pensado para organizar la información en diferentes secciones y ofrecer una experiencia de uso clara e intuitiva.

## 🚀 Instalación y ejecución

1. Descargar o clonar el repositorio.
2. Abrir el proyecto desde Android Studio.
3. Esperar a que Gradle sincronice las dependencias.
4. Seleccionar un emulador o conectar un dispositivo Android compatible.
5. Ejecutar la aplicación desde Android Studio.

## 📂 Estructura del proyecto

El proyecto sigue la estructura habitual de una aplicación Android:

- `app/src/main/java/`: contiene las clases Java y la lógica de la aplicación.
- `app/src/main/res/layout/`: contiene los diseños XML de las pantallas.
- `app/src/main/res/drawable/`: contiene las imágenes, los iconos y otros recursos gráficos.
- `app/src/main/res/values/`: contiene recursos como colores, textos y temas.
- `AndroidManifest.xml`: define información básica de la aplicación y sus componentes.
